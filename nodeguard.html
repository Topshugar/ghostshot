🛡️ NODEGUARD
Is your Bitcoin Node exposed? Check your bitcoin.conf before hackers do. 100% offline — nothing leaves your browser.

1. Paste your bitcoin.conf

IMPORTANT: Delete your rpcpassword=... value before pasting. Replace it with rpcpassword=***. We don't need your real password to check if you're exposed.

2. What we check

• rpcbind / rpcallowip: If it's 0.0.0.0 or 0.0.0.0/0, anyone on internet can try your RPC.
• server=1: If missing, RPC is off (safe but node won't work for wallet).
• rpcuser / rpcpassword: If missing or too short, auth is weak.
• testnet: If you're on mainnet with RPC open, risk is CRITICAL.

3. How to fix if EXPOSED

Copy this safe config:

rpcbind=127.0.0.1
rpcallowip=127.0.0.1
rpcuser=change-this-user
rpcpassword=change-this-to-32-random-chars
server=1
daemon=1

Then restart: bitcoin-cli stop && bitcoind -daemon

Also check firewall: Port 8332 should be CLOSED from outside. Port 8333 can be OPEN if you want to be a public node.
